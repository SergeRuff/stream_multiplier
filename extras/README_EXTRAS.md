Директория содержит реализацию устройства, описанного в техническом задании, но с одной оговоркой - реализация выполнена на языке SystemVerilog. Функционально устройство идентично тому, что лежит в [исходной папке](../solution).

Запуск верификации осуществляется с помощью скриптов [run_tb_sv.bat](./run_tb_sv.bat) и [run_tb_sv.sh](./run_tb_sv.sh) для cmd (Windows) и shell (Linux) соответственно.
